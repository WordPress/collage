# Bundled conversion library

Collage uses the native PHP Pandoc port and its MarkerPDF reader from
[adamziel/port-libs](https://github.com/adamziel/port-libs).

- Original revision: `0e89f7f4e19cefb961e5ee2de61145b4f0c018fc`
- Source: `lib/pandoc/` was imported from `lanes/pandoc/src`; `lib/markerpdf/`
  contains the PDF text reader files and resources previously shipped from
  `lanes/markerpdf/src`.
- Original port code: MIT, as declared in the pinned upstream `composer.json`.
  That declaration does not replace the terms of the resources listed below.

The source is maintained in Collage. Composer generates the class map
from the tracked files. MarkerPDF's OCR pipeline and its Surya and Tesseract
language tables are not distributed in the plugin. The target WordPress site
does not need Composer or a Pandoc executable.

The local test site uses WordPress and the WordPress Performance Team’s SQLite
Database Integration plugin. Neither is bundled in the plugin ZIP.
