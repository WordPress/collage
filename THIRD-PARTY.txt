# Bundled conversion library

Collage uses the native PHP Pandoc port and its MarkerPDF reader from
[adamziel/port-libs](https://github.com/adamziel/port-libs).

- Revision: `0e89f7f4e19cefb961e5ee2de61145b4f0c018fc`
- Source: `lanes/pandoc/src` and `lanes/markerpdf/src`
- License: MIT, as declared in the upstream `composer.json`

The setup script copies those source directories unchanged. Composer generates
the class map. The plugin ZIP includes both readers and the class map; the target
WordPress site does not need Composer or a Pandoc executable.

The local test site uses WordPress and the WordPress Performance Team’s SQLite
Database Integration plugin. Neither is bundled in the plugin ZIP.
