# Field notes

Some ideas arrive fully formed. Most start as a few words in a notebook.
These are the ones worth keeping.

## A little less noise

The best work often starts with a simple question: **what can we leave out?**
Not every thought needs a meeting. Not every plan needs a slide deck.
Sometimes a short note is enough.

> Make space for the work you want to do, not just the work that arrives.

## This week’s small experiments

- Start the morning with a blank page, not an inbox.
- Write down one thing you learned each day.
- Share a work in progress before it feels ready.

## Keep what works

| Try this | Instead of this |
| --- | --- |
| A clear first draft | A perfect opening sentence |
| One useful question | Another status meeting |
| An afternoon walk | One more open tab |
